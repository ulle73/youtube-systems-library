## What this system does

This is a staged website-production workflow, not a one-prompt site generator. It moves from a proven design reference to a complete sitemap, implementation, custom assets, an interactive conversion element, mobile QA, copy cleanup, UI polish, SEO planning, and deployment.

The core pattern is:

`reference -> site map -> wireframes/style -> Claude build -> critique -> assets -> conversion interaction -> mobile QA -> copy QA -> UI polish -> SEO -> deploy`

## Why save this as a system

The video contains a concrete build order and a set of named dependencies. Future agents should reuse this implementation sequence before inventing a new website workflow from model priors.
