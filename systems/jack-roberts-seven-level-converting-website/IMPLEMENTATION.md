# Implementation

## Required setup

### Core
- Claude/Claude Code/Claude Design capable of ingesting files and URLs.
- Relume account for sitemap/wireframe/style export.
- A reference-site discovery source such as refero.design.

### Optional but demonstrated
- Higgsfield integration for generated image/video assets.
- Savee for interaction/UI inspiration.
- Design Loop skill for iterative design critique.
- SlopMonster for copy quality.
- 21st.dev/Relume components.
- Flaticon/Icons8/IconScout.
- SEO repository/skill.
- GitHub + Vercel.

## Build contract

### Phase A — blueprint
1. Document business, target visitor, offer, required pages and real proof.
2. Select one reference site and record **what** is being borrowed: layout logic, spacing, color system, typography hierarchy, image behavior, motion/interaction — not copyrighted copy/brand assets.
3. Generate the full sitemap in Relume.
4. Review every page/section manually.
5. Finalize wireframes and style guide.
6. Export HTML ZIP and retain original reference URL.

### Phase B — implementation
7. Give Claude the business brief, ZIP and reference URL.
8. Build from the blueprint rather than asking Claude to invent the information architecture.
9. Run the Design Loop. Keep critique outputs separate from source facts.

### Phase C — conversion assets
10. Connect Higgsfield and generate a coherent asset set.
11. Add one high-value interactive element where it improves the page's job. For lead gen, return value before requesting contact details.

### Phase D — QA
12. Mobile optimize. Test viewport widths manually.
13. De-slop visible copy. Never create statistics/testimonials to make the page sound convincing.
14. Replace weak components/icons with proven components and brand-fit icons.

### Phase E — acquisition + launch
15. Run SEO research from actual customer intent and keyword inputs.
16. Produce a prioritized page/content roadmap; don't auto-publish low-confidence keyword content.
17. Put code in a private GitHub repo and deploy to Vercel.

## Acceptance checklist
- [ ] Full sitemap exists before final visual polish.
- [ ] Reference design is recorded and traceable.
- [ ] Mobile checked manually.
- [ ] Every factual proof claim is real and sourced.
- [ ] No unresolved placeholder testimonial/metric ships.
- [ ] Interactive element gives visitor value.
- [ ] SEO plan maps keywords to user intent/pages.
- [ ] Deployment source repository is private.
