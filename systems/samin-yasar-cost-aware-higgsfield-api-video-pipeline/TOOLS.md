## Higgsfield API
Current provider facts verified 2026-09-20:
- separate from the higgsfield.ai website subscription;
- 50+ current models behind one API key;
- pay per generation with public per-model rates;
- self-serve key flow;
- asynchronous request/status integration.

Sources:
https://higgsfield.ai/higgsfield-api
https://higgsfield.ai/blog/higgsfield-api
https://higgsfield.ai/creator-hub/help-center/integrations/what-is-the-higgsfield-api
