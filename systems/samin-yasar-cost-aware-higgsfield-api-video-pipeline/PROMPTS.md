# Prompts

The captured evidence does not expose enough exact prompt text to reproduce the creator's skill faithfully. These are analytical reconstructions, not creator quotations.

## Storyboard-only prompt — INFERRED
Turn the approved creative brief into a shot-by-shot storyboard. Do not generate video or trigger any paid API call. For each shot specify purpose, approximate duration, action/camera movement, required reference, text/audio requirement and continuity constraint. End with the minimum preview/reference images needed to choose direction.

## Cost-aware routing instruction — RECONSTRUCTED
Use staged video production. Plan and preview first. Use configured draft models for exploration. Do not call a premium model until a direction is selected. Before each paid call, surface model, stage, duration and known estimated cost. After each call, record request/job ID, actual charge if available, status and result. Stop when the budget ceiling is reached. Never retry an uncertain request before checking existing status.

## Candidate review — INFERRED
Compare draft candidates with the approved brief for message intent, motion coherence, product/identity fidelity, text/UI fidelity and audio. Select at most one direction for premium generation. If none is viable, explain why without spending more.
