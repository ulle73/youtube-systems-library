## Core mechanism

Story → storyboard/images → lower-cost video drafts → choose winner → premium final → cost/result record.

The durable idea is progressive spending. Exploration is cheap; premium spend starts only after uncertainty has been reduced and a direction has been selected. Current Higgsfield documentation independently confirms that its API is a separate pay-per-generation product with public per-model pricing.

The source also shows a reusable skill and later a client-facing site. Those are optional packaging layers, not prerequisites for the production method and not proof of product demand.
