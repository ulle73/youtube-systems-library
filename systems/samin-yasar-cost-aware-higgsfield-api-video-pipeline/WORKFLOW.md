# Workflow

## 0. Preflight — RECONSTRUCTED
Confirm creative goal, duration/aspect ratio, review criteria, reference-media permissions and a spending ceiling. Refresh current model prices and capability. Temporary launch discounts must not become permanent routing rules.

## 1. Plan story — EXACT
At 13:03–13:14 the source plans the story in ChatGPT and requests a shot-by-shot storyboard.

## 2. Produce previews — EXACT
At 13:08 onward the source generates images/previews so the visual progression can be inspected before video spend.

## 3. Generate lower-cost drafts — EXACT
At 13:51–14:03 the source recommends multiple short candidate clips with cheaper models such as MiniMax.

## 4. Select direction — EXACT
At 14:03–14:08 the source chooses the direction after candidate generation.

## 5. Premium finish — EXACT
At 14:08–14:26 the source uses the more expensive model/workflow for the winner or final transformation.

## 6. Review — RECONSTRUCTED
Inspect temporal quality, identity/product fidelity, text/UI, audio and end state. Record accepted/rejected and why.

## 7. Write back — RECONSTRUCTED
For every paid job record provider/model, seconds, request ID, status, actual charge when available, attempt number, acceptance and review time. Measure cost per accepted output, not cost per raw generation.

## 8. Package recurring logic — RECONSTRUCTED
The creator packages the workflow into a skill and later a site. Do this only after repeated manual runs prove stable rules.

## Failure handling

For uncertain API state, check the existing request before submitting another. If model prices or IDs change, refresh the catalog. If cheap drafts do not predict premium quality, stop using them as a proxy. If packaging costs more than it saves, return to the manual staged workflow.
