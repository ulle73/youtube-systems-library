# Tools and roles

Tool names below are source-stated and transcript spellings are imperfect. Treat current product docs as source of truth before implementation.

## GPT-6 Astra / Codex
**Source role:** market/niche ideation, orchestration and a skill-like generation workflow.

**Evidence status:** EXACT as described by the creator; exact account capability and the linked private skill were not inspected.

## KinetAI
**Source role:** avatar creation, persistent character generation and API-driven image batches.

**Evidence status:** source-stated/demonstrated. No independent cost, quality, licensing or API test was performed.

## Seedance-style video generation
**Source role:** animate a generated still into a short video.

**Evidence status:** source-stated; auto-captions render the name inconsistently. No independent run was performed.

## Instagram
**Source role:** discovery/top-of-funnel channel.

**Evidence status:** EXACT. The video's algorithm and anti-detection claims are not validated and are excluded from implementation.

## Fanvue
**Source role:** subscription destination, tracking links, automated messages, PPV and creator monetization.

**Evidence status:** source-stated and current help material confirms AI creators, subscriptions, PPV and AI-disclosure rules. Platform policy can change.

## TipChat.ai
**Source role:** automated conversation/persona configuration, templates and optional human handoff.

**Evidence status:** source-stated/demonstrated. No independent reliability, privacy, safety or conversion test was performed.

## Integration rule
A tool is replaceable. Preserve the contracts:
- persistent persona spec;
- rights/disclosure gate;
- generation records;
- tracked CTA;
- bounded automation;
- human escalation;
- downstream measurement.
