# Prompt scaffolds

These are new safe reconstruction prompts, not copied prompts from the source.

## 1. Persona / brand brief

> Build a persistent synthetic brand/persona specification for [audience] whose purpose is [business/communication job]. The persona must be clearly disclosed as synthetic where used. Use only the supplied owned/licensed references. Define visual constants, tone, recurring themes, allowed claims, forbidden claims, and five content situations. Flag any instruction that conflicts with platform policy or asset rights instead of working around it.

## 2. Short-form creative batch

> Using the approved persona/brand brief, draft [N] short-form concepts. For each, specify Hook, Buildup, Trigger, Reaction/Resolution, CTA, target audience, destination, and one measurable hypothesis. Keep factual claims within the approved source material. Do not optimize for deception or platform-evasion tactics.

## 3. Measurement review

> Review this batch using downstream evidence rather than views alone. Compare creative/test ID, watch/engagement signals, destination visits, conversion, repeat behavior if available, production cost, reject rate and human corrections. Separate observed results from hypotheses. Recommend at most one rule change for the next batch and state what evidence would falsify it.
