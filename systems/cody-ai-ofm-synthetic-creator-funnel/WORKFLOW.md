# Workflow

1. **Define the commercial job — EXACT/RECONSTRUCTED.**
   State the target audience, desired downstream action and the value proposition. Do not start from "make an AI influencer."

2. **Write the persona/brand specification — EXACT.**
   Fix a narrow identity, tone, visual markers, recurring interests/themes and content boundaries before generating a batch.

3. **Resolve rights and disclosure — RECONSTRUCTED.**
   Use only owned/licensed references. Confirm current platform rules. Make synthetic identity/automation transparent where required.

4. **Generate a bounded creative batch — EXACT.**
   Produce multiple consistent stills from the stable specification, then animate selected assets. Record tool/model/settings and rejected outputs.

5. **Apply the short-form grammar — EXACT.**
   Use hook → buildup → trigger → reaction → CTA as one testable format, not as a universal truth. Vary only what the experiment requires.

6. **Attach a tracked CTA — EXACT.**
   Create a channel/campaign-specific destination or tracking parameter before publishing. Preserve attribution through the next funnel step.

7. **Automate only low-risk onboarding — RECONSTRUCTED.**
   Greetings, FAQ/context collection and routing can be automated transparently. Do not imitate a real human or use fabricated intimacy as the control mechanism.

8. **Escalate when needed — RECONSTRUCTED.**
   Hand off cases that exceed the automation's approved scope, require judgement, or involve sensitive/commercial exceptions.

9. **Measure the full path — INFERRED.**
   Track creative archetype → traffic → destination behavior → conversion → repeat/retention → cost/human effort. Do not equate views or generated-asset count with success.

10. **Write learning back — INFERRED.**
    Update the persona/creative rules only when repeated measured evidence justifies the change.
