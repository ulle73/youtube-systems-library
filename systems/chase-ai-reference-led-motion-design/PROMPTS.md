# Prompts

## Provenance
The following is a new **INFERRED** prompt for applying the reconstructed method. It is not a verbatim creator prompt or a tested production prompt. Original source prompts belong to the upstream package; use its complete archived source and adaptation guide rather than pretending this abbreviated request reproduces them.

## Draft-only request
```text
Develop one short-film brief for the communication goal and approved assets I provide.

First state the audience, single takeaway and intended destination. Choose a suitable source example by communication function. Read its complete available prompt and explain what you retain and deliberately change. If the original prompt is unavailable, say so.

Return one resolved full-film prompt with timed beats, transitions, exact on-screen text, reading holds, audio direction and ending. Keep factual claims limited to verified inputs. Preserve real product/UI material; do not invent screens, numbers, conditions or endorsements.

List the minimum reference assets and each role: identity, style, motion or actual source media. Identify only genuinely missing assets. Distinguish an illustrative generated depiction from source-preserving media.

This is prompt review only. Do not generate images, upload assets, submit video jobs, connect accounts or spend credits. State the capability and price checks required before a separately authorized run. Do not claim that a render or test occurred.
```

## Review request
```text
Compare the produced film with the approved brief and actual source assets. Inspect complete playback and audio, not only stills. Separate communication failures from technical defects. Check exact copy, factual claims, identity, timing, transitions and ending. Record what you did not inspect. Propose the smallest correction and its cost implications; do not start another job without existing authorization and budget.
```

Customization fields: goal, audience, destination, duration/aspect ratio, approved copy, source reference, permitted assets, audio, success criteria and budget boundary. Missing production fields do not block useful draft-only analysis, but must not be silently invented before submission.
