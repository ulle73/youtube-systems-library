## Critical billing distinction
Official Higgsfield guidance says programmatic generations through MCP, CLI and other automated surfaces consume normal credits, even when a manual website plan includes free/unlimited generation. A public prompt package is not a free renderer. Manual use is cheaper only when the actual account allowance covers the needed model and mode. [H1]

## Route distinction
The creator package uses Higgsfield MCP for video. Current provider guidance recommends CLI for coding agents. These are separate interfaces; adapting the package requires preserving approval stops, capability checks, asset binding and job-state handling. No installed connection or drop-in compatibility was tested. [R2, H2, H3]

## Accounting identity — analytical proposal
`Cost per accepted film = (allocated assistant cost + all charged image/video/edit jobs + review/finishing cost) / accepted films`

Include rejected attempts. No empirical time saving or commercial return is established. At a cap of two video jobs per concept, ten concepts can involve up to twenty video jobs, excluding separately charged assets and finishing; this is a scenario, not a price quotation.
