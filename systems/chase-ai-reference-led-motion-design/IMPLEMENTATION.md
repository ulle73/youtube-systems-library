# Implementation runbook

**Not executed or runtime-tested.** This is a source-backed setup plan, not an installed integration.

## Minimum version
Start with an existing assistant, one approved brief and relevant source examples. Produce and review the complete prompt before connecting a paid renderer. No new application, asset database or automation platform is required to test the planning method.

## Optional source-package adoption
1. Inspect the current creator repository at https://github.com/cth9191/motion-design and its setup documentation. The shared package lives at `skills/motion-design/` and contains references, templates and gallery assets; copying only its entrypoint loses required context.
2. Follow the current host-specific installation instructions rather than the video's generic invocation shorthand. The inspected README distinguishes Codex `$motion-design` from Claude Code `/motion-design`.
3. Preserve local customizations when updating an installed copy. Record the version or commit inspected. Public availability does not remove the need to review license and asset rights.
4. Connect an authorized Higgsfield account using current official instructions. Do not place credentials or customer data in prompts or this repository. Source-package MCP routing and provider-recommended CLI routing must be reconciled before execution.
5. Check actual account entitlement, model duration, aspect ratio, reference roles, audio and price without creating a job. A model appearing in a catalog is not proof of entitlement.
6. Run one authorized concept and at most one agreed correction; inspect the actual output. Save requests, job records and review results. No paid run is commissioned by this document.

## Acceptance test — INFERRED
Use identical message and assets to compare with the current editing route. Required: correct claims, recognisable product, exact important text, readable ending and acceptable motion/audio. Measure all billed jobs and active work. Stop when spending cannot be bounded or output needs more repair than the baseline. No savings threshold or conversion gain has been empirically established.
