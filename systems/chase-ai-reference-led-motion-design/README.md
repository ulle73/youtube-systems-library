## Problem and mechanism
Translate a rough communication goal into a reviewable short-film specification, then into an inspected output. The assistant handles direction and adaptation; Higgsfield and the selected video model render the film. This is not a native application animation library or a deterministic motion editor.

`Goal → source example → complete adapted brief → minimal assets → authorized full-film job → playback review → bounded correction → accepted-output record`

The reusable unit is the production contract, not a particular model name. Keep source prompts immutable, company facts external, references role-labelled and billed actions explicit.
